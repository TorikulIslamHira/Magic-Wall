তারপর ওপরে একটি আসনে যোগ করুন।

ম্যাচ ও খেলোয়াড়

ওয়াল কার ঘটনা বিশ্লেষণ করবে তা বেছে নিন।

ঘটনা যোগ করুন

অবস্থান দিতে মাঠে স্পর্শ করুন। পাস বা শটের তীর আঁকতে টেনে ধরুন।

অবস্থান ঠিক করা হয়নি

নথিভুক্ত ঘটনা

সর্বশেষটি আগে।

মিনিটধরনশুরুশেষ

ওয়ালে কী দেখাবে

তারিখ ফাঁকা রাখলে সর্বশেষ ঘটনা থেকে শুরু হবে; অঞ্চল ফাঁকা রাখলে সব অঞ্চলের সারসংক্ষেপ।

এই অঞ্চলের টাইমলাইন

প্রতিটি ঘটনা ওই তারিখ থেকে অঞ্চলের নিয়ন্ত্রণ নির্ধারণ করে।

তারিখনিয়ন্ত্রণেহতাহতবিবরণ

নতুন সংঘাতপূর্ণ অঞ্চল

মানচিত্র কোড হলো বিশ্ব মানচিত্রে দেশের কোড, যেমন SDN, UKR, MMR (দক্ষিণ সুদান = SDS)।
